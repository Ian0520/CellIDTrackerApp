# Retired floor inference work

Archived November 17, 2026, at the user's request. These sources and their tests
are historical records, excluded from the active floor workflow. Their original
imports and command interfaces are frozen and are not maintained here.

The only active algorithm is presence-only current-cell lookup in
../../floor_algorithm_study.py. Its measurement-quality helpers are independent
of these retired models. Do not use the archived scores, frequency methods,
history intersection, temporal controls or fallback rules as current results.

Original input captures and historical output directories remain available for
research provenance. Any new algorithm requires a deliberate future decision;
none of these is an enabled alternative or baseline.
