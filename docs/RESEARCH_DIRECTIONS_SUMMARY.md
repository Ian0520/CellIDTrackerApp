**我們的條件：** 依使用者確認的方法條件，本輪以「成功收到的 Cell ID 是該次量測的最新值」評估；主叫端每次 probe 至多取得一筆。沒有目標端即時 GPS、Wi-Fi 掃描、訊號強度或感測器作推論輸入。目標端量測只作真值、校準與控制。兩次 probe 之間的切換可能未被觀察；失去 Wi-Fi 而沒有 CNI 時，結果仍是未知。

## A. 定位精確度與場所資訊

### 1. 建築物／區域辨識（你的建築物方向＋我的多筆 ID 分布）

- **簡介：** 利用室內專用 cell，或短時間 ID 分布與切換模式，分辨建築物及內部區域。
- **成功模擬：** 甲館、乙館首筆都是 A；後續甲館常 A/B、乙館常 A/C，因此辨認所在館別。
- **論文前提與結果：** [PlaceSense（2009）](https://www.cs.ucf.edu/~lboloni/Teaching/EEL6788_2010/papers/Kim-PlacesRFBeacons.pdf)：手機每 10 秒讀目前 GSM cell，另有 Wi-Fi AP 版本；3 人進行 30 個場所的腳本測試與各 4 週日常測試。GSM 版本容易合併鄰近場所；整體 **92% 場所召回率是 Wi-Fi 版本的結果**（Table 4）。
- **與我們不同：** 它直接讀目標手機 cell／周遭 AP；我們只在成功 probe 時取得單一最新 cell，沒有 AP 清單。論文未驗證建築物辨識或我們提出的短期 ID 分布指紋。

### 2. 樓層／垂直區域辨識（你的方向）

- **簡介：** 用不同樓層的室內 cell 差異與事前校準，辨認樓層或地下／地上區域。
- **成功模擬：** 已知人在百貨公司，再辨認地下停車場或三樓，提供對應區域資訊。
- **論文前提與結果：** [Floor Detection…（2015）](https://spcomnav.uab.cat/docs/conferences/DelPeral_GLOBECOM_2015.pdf)：兩層樓部署 4 個 LTE 小型基地台，已知其高度，現場接收設備辨認實體 cell ID。約 160 秒測試中，**僅靠 ID 的樓層正確率 69.88%**、垂直誤差 RMSE 1.79 m（Table I）；超過 98% 屬於另有感測器的方法。
- **與我們不同：** 我們讀到的是 CNI 中的全球 cell 身分，尚無已驗證的樓層對應與可控室內部署；論文使用本機取得的實體 ID，不能直接套用其結果。

### 3. Cell 切換定位地標（我的方向）

- **簡介：** 校準 A→B 轉換常出現的區段，利用「剛切換」縮小位置範圍。
- **成功模擬：** B 涵蓋大片區域，但剛從 A 切到 B，便將位置縮小到某段入口通道。
- **論文前提與結果：** [CAPS（2011）](https://cseweb.ucsd.edu/~schulman/class/cse291_w17/docs/paek_caps.pdf)：手機約每 2.5 秒讀目前 Cell ID，先收集 6 趟 GPS 路線，用序列與時間估計進度，必要時重開 GPS。四條主要已學習路線的定位誤差中位數 **31～72 m**（Table 4）。
- **與我們不同：** 探測間隔可能漏掉短暫切換；即使每筆 cell 都最新，仍不知道兩次 probe 之間確切何時切換，且不能用即時目標 GPS 補救。論文未測室內入口地標，也未證明單次切換能達到入口尺度。

### 4. 地圖與歷史限縮候選位置（我的方向）

- **簡介：** 結合可信起點、經過時間、動線與目前 cell，保留較小的可能位置集合。
- **成功模擬：** B 涵蓋整棟建築；根據剛才的入口位置與後續歷史，把候選縮小到西館幾個區域。
- **論文前提與結果：** [Cell*／From Cells to Streets（2014）](https://conferences.sigcomm.org/co-next/2014/CoNEXT_papers/p121.pdf)：使用每次 sector 切換、業者天線／功率／覆蓋資料、完整起終點與車行路網。30 人、3,216 趟資料中，GPS 點到**整條推估路徑**的最短距離中位數 **70 m**；靜止位置誤差中位數 **230 m**（§5）。
- **與我們不同：** 我們缺業者部署資料，也不知道未來終點。70 m 不是對應時間的即時位置誤差；論文未驗證室內定位，最終路徑推估也不使用時間進度。「時間＋室內動線」是我們的延伸假說。

## B. 移動、預測與減少探測

### 5. 開始移動、停下與重新出發（我的方向）

- **簡介：** 用 ID 數量、持續時間與回跳模式，辨認粗略停留／移動狀態。
- **成功模擬：** 原本停留的人開始跨區域移動，系統重新確認位置並縮短查詢間隔。
- **論文前提與結果：** [Parsimonious Mobility Classification…（Mun 等，2008，作者原文）](https://www.researchgate.net/publication/228523926_Parsimonious_mobility_classification_using_GSM_and_WiFi_traces)：1 人、2 天，手機每 2 秒讀 GSM cell 與 Wi-Fi；隨機三折驗證，**GSM＋Wi-Fi 的停留／步行／開車三類正確率 83%**。88% 是移除室內停留後的行人／車輛二分類（§3）。
- **與我們不同：** 我們沒有目標 Wi-Fi 掃描，CNI 也較稀疏。「停留」定義為在一處超過 5 分鐘，可包含局部走動；論文未驗證瞬間停下／重新出發，亦未驗證跨人、跨日泛化。

### 6. 方向、回頭與路線偏離（我的方向）

- **簡介：** 根據 ID 順序與已學習路線，分辨前進、反向、折返或分岔。
- **成功模擬：** 現在都是 B，但 A→B 與 C→B 對應不同路線進度，因此辨認正接近或遠離接送點。
- **論文前提與結果：** [CAPS（2011）](https://cseweb.ucsd.edu/~schulman/class/cse291_w17/docs/paek_caps.pdf)：資料與 GPS 前提同第 3 項。序列匹配可估計已學習路線進度，但**沒有回頭／偏離偵測率**；作者明確指出，**不同路線若 Cell ID 序列相同，就無法區分**（§6）。
- **與我們不同：** 我們缺它的連續手機讀值與即時 GPS 補救。它提供序列匹配方法依據，方向／回頭辨認仍是我們需要另測的能力。

### 7. 下一區域／近期到達預測（我的方向）

- **簡介：** 用已觀察的路線進度，預測下一區域或近期到達的機率。
- **成功模擬：** 人尚未抵達服務點，系統預測可能即將到達，提前準備接送或相關資訊。
- **論文前提與結果：** [VisitSense（2015，出版商提供原文）](https://www.researchgate.net/publication/281853045_VisitSense_Sensing_Place_Visit_Patterns_from_Ambient_Radio_on_Smartphones_for_Targeted_Mobile_Ads_in_Shopping_Malls)：場所感測用手機 Wi-Fi 指紋＋加速度。**預測另用 76 人／351 次問卷到訪紀錄**，輸入前兩次場所類別、時間、停留時間、年齡與性別；80/20 分割，下一類別第一名正確率 **59.45%**、前兩名 **70.27%**（§5.3）。
- **與我們不同：** 預測輸出只有店舖／咖啡館／餐廳／娛樂四類，沒有確切下一家店、到達時間或期限內到達結果；也不是用自動感測資料驗證完整流程。我們的 CNI 不直接提供上述到訪紀錄與感測輸入。

### 8. 離開區域偵測與減少 probe（你的方向，整合動態排程）

- **簡介：** 先辨認離開事件，再調整查詢間隔，衡量次數、誤報與偵測延遲；仍保留定期檢查。
- **成功模擬：** 在有可辨識離開訊號的場域，停留時少查詢，離開後仍能在約定延遲內通知。
- **論文前提與結果：** [PlaceSense（2009）](https://www.cs.ucf.edu/~lboloni/Teaching/EEL6788_2010/papers/Kim-PlacesRFBeacons.pdf) 的感測與結果同第 1 項；提出以粗略 GSM 觸發 Wi-Fi 精細感測，**沒有量化查詢節省**，離開事件圖也排除了實際判定延遲。另有 [AoII／pull-based state estimation（2026 預印本）](https://arxiv.org/html/2608.13248v1)：已知狀態轉移模型，成功查詢立即取得真實狀態；數值模擬中，等待後連續查詢的策略成本接近模型最佳策略（§II、IX）。
- **與我們不同：** PlaceSense 提出的是目標手機粗／細感測切換設計；AoII 假設失敗與狀態變化獨立。即使收到最新 cell，也未必能確定區域內／外的真實狀態；缺資料可能取決於所在位置的 Wi-Fi。兩篇都未驗證我們管道的離開準確率或 probe 節省。
